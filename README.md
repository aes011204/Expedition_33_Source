# Expedition 33 — 모작 프로젝트

《클레르 옵스퀴르: 33 원정대》의 전투 시스템을 구현한 C++ / DirectX 11 기반 팀 프로젝트입니다.

턴제 전투에서 행동을 선택하는 전략적 요소와, 적의 공격에 패링·회피·점프로 대응하는 실시간 입력 요소를 구현하는 데 중점을 두었습니다.

> 이 저장소는 게임 리소스를 제외한 소스 코드 공개용 저장소입니다.
> 모델·텍스처·음원 등의 리소스는 포함하지 않습니다.

## 담당 기능

### 턴제 전투 흐름

- FSM을 활용한 행동 선택 및 실행 흐름 관리
- 행동 선택 상태에 따른 UI 표시 및 입력 처리
- 선택한 스킬 정보를 실행 단계로 전달

### 데이터 기반 스킬 실행

- JSON으로 스킬별 이동량과 제자리 공격 여부 관리
- 선택한 스킬의 데이터를 읽어 공격 동작과 연출 처리

### 실시간 대응 입력

- 애니메이션 노티파이를 활용해 입력 판정 구간 설정
- 판정 구간에서 대응 입력을 받아 결과 처리
- 판정 구간 종료까지 입력이 없는 경우 실패 처리

## 주요 설계

### FSM을 통한 전투 상태 관리

행동 선택과 실행 흐름을 상태로 나누어 관리했습니다.
각 상태의 역할에 맞춰 UI와 입력 처리를 연결하고,
선택한 행동 정보를 다음 실행 단계로 전달하도록 구성했습니다.

### 스킬 데이터 분리

스킬별 이동량과 공격 방식을 JSON 데이터로 분리했습니다.
공통 실행 흐름에서 스킬 데이터를 읽어 서로 다른 공격 동작을 처리했습니다.

### 애니메이션과 입력 판정 연결

공격 애니메이션에 노티파이를 배치해 입력 판정 구간을 제어했습니다.
이를 통해 공격 동작에 맞춰 대응 입력의 판정 시점을 지정했습니다.

## 프로젝트 구조

| 경로 | 역할 |
|---|---|
| `Engine` | 공통 엔진 코드 |
| `Client` | 게임 로직 |
| `GameLauncher` | 게임 실행 프로젝트 |
| `MainEditor` | 메인 에디터 |
| `MapEditor` | 맵 에디터 |
| `ModelEditor` | 모델 에디터 |
| `UI_Editor` | UI 에디터 |
| `EffectEditor` | 이펙트 에디터 |
| `BatchTool` | 데이터·리소스 가공 도구 |

셰이더 소스는 각 프로젝트의 `Bin/ShaderFiles` 경로에 포함되어 있습니다.

## 빌드 및 실행 안내

이 저장소에는 게임 실행에 필요한 리소스와 일부 외부 라이브러리가 포함되어 있지 않습니다.
저장소를 클론하는 것만으로 게임을 바로 실행할 수는 없습니다.

빌드를 위해서는 다음 준비가 필요합니다.

- Visual Studio의 C++ 개발 환경 및 Windows SDK
- `vcpkg.json`에 정의된 의존성 설치
- FMOD 등 별도 SDK 및 라이브러리 준비
- 개발 환경에 맞는 라이브러리 경로 설정
