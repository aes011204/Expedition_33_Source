# Expedition 33 모작 프로젝트

《클레르 옵스퀴르: 33 원정대》를 C++20과 DirectX 11 기반으로 구현한 팀 프로젝트입니다.

턴제 전투의 전략적인 행동 선택과 패링·회피·점프를 통한 실시간 대응을 구현했습니다.
저는 **턴제 전투 시스템, 몬스터·보스 행동 시스템, Behavior Tree 에디터**를 담당했습니다.

> 팀 프로젝트에서 게임 리소스를 제외하고 개인 기여 내용을 정리한 소스 코드 공개용 저장소입니다.
> 모델·텍스처·음원 등의 게임 리소스는 포함하지 않습니다.

## 담당 기능

### 턴제 전투 시스템

- 속도 기반 턴 스케줄링과 행동 순서 관리
- 단계별 행동 실행, 이동 및 전투 연출 제어
- 애니메이션 이벤트를 통한 전투 동작과 처리 시점 동기화
- 다단히트 예약 및 타격 처리
- 실시간 방어 반응과 QTE 입력 판정

### 몬스터·보스 행동 시스템

- 월드 몬스터와 배틀 몬스터의 구조 분리 및 전환
- 필드 몬스터의 인지·순찰·추적 행동
- 점수 기반 스킬 및 타깃 선정
- Behavior Tree와 상태 머신을 활용한 보스 행동 제어

### Behavior Tree 및 AI 제작 도구

- 자체 Behavior Tree 실행 구조 구현
- Behavior Tree 편집 및 데이터 로딩
- 실행 중 행동 흐름을 확인하기 위한 런타임 디버깅

세부 구현과 문제 해결 과정은 별도 포트폴리오 사이트에 정리할 예정입니다.

## 팀 프로젝트 전체 구조

아래는 팀 전체 프로젝트의 구성입니다.
제가 직접 구현한 부분은 위의 ‘담당 기능’ 항목에 별도로 정리했습니다.

| 경로 | 역할 |
|---|---|
| `Engine` | 공통 엔진 코드 |
| `Client` | 게임 로직 |
| `GameLauncher` | 게임 실행 프로젝트 |
| `MainEditor` | 메인 에디터 |
| `MapEditor` | 맵 에디터 |
| `ModelEditor` | 모델 에디터 |
| `UI_Editor` | UI 에디터 |
| `EffectEditor` | 이펙트 에디터 |
| `BatchTool` | 데이터·리소스 가공 도구 |

셰이더 소스는 `Engine`, `Client`, `MapEditor`, `ModelEditor`의
`Bin/ShaderFiles` 경로에 포함되어 있습니다.

## 사용 라이브러리

- 모델·물리·사운드: Assimp, PhysX, FMOD
- 그래픽 보조: DirectXTK, Effects11
- 편집 도구 및 디버깅: ImGui, ImPlot, ImGuizmo, imgui-node-editor
- 데이터 및 유틸리티: nlohmann/json, magic_enum, spdlog, stduuid, tinygltf

## 빌드 및 실행 안내

게임 실행에 필요한 리소스와 일부 외부 라이브러리가 포함되어 있지 않아,
저장소를 클론하는 것만으로 게임을 바로 실행할 수는 없습니다.

빌드를 위해서는 다음 준비가 필요합니다.

- Visual Studio의 C++ 개발 환경 및 Windows SDK
- `vcpkg.json`에 정의된 의존성 설치
- FMOD 등 별도 SDK 및 라이브러리 준비
- 개발 환경에 맞는 라이브러리 경로 설정
